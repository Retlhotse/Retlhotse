I am building an AI agent with sub agents that will query a database for components or applications, data quality, governance questions and just general info-desk type of questions. The user will prompt the orchestrator agent that will classify the question and pick which sub agent to use. The sub agents will represent my different business requirements.

Each sub agent after receiving the prompt from the orchestrator agent, the sub agent must come up with a plan based off of the tools or function calls it has. Each sub agent will have different tools that the sub agent can call and these tools will be used to query different tables. Once it gets back the results, it will send them back to the orchestrator agent.

My sub agents are based off of business requirements for this applications. Each sub agent is going to get the schema configuration of the database tables that it deals with as part of its system prompt in order for the agent to build custom queries to query the database based off of the prompt that's coming in from the user. These are the different sub agents I want:
- sub agent for info desk. This one will deal will questions about navigating my website and how to implement certain parts of the website.
- A data quality sub agent. This agent will deal with questions about data quality issues so that I can identify root causes and impacted applications.
- A data quality improvement guidance sub agent. This sub agent will recommend actions to improve data quality for specified applications.
- An application sub agent. I want to search for an application or applications and get a complete, consolidated view so that I understand its purpose and dependencies.
- governance and controls sub agent. I want to ask the AI about governance rules and compliance status so that I can assess risk quickly. 

This is a python backend microservice application. use langchain frameworks and pydantic for validation. Use OpenAi api for the LLM. For the database that's being queried, use PostgreSQL and for the vector database, use weaviate
