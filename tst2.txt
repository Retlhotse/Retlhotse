graph TD
    %% User/Config Layer
    subgraph User Interface / Configuration
        A[User / Enterprise Admin] -->|1. Define Model Details<br>Base URL, API Keys, System Prompts| B(Configuration UI / CLI)
        A -->|2. Select Test Metrics<br>e.g., Tool Correctness, Faithfulness| B
    end

    %% Orchestration Layer
    subgraph Evaluation Pipeline Orchestrator
        B -->|3. Trigger Evaluation Run| C[Evaluation Worker / Runner]
        
        subgraph DeepEval Framework
            C -->|4. Initialize Test Cases| D[DeepEval Test Suite]
            D -->|5. Invoke Agent/Model under test| E[Target Agent / LLM]

            D -->|7. Send Payload to Judge| F[LLM-As-A-Judge<br>GPT-4o / Claude 3.5]
            F -->|8. Return Scores & Reasons 0-1| D
        end
    end

    %% Data Layer
    subgraph Storage Layer
        D -->|9. Export Structured JSON Results| G[(PostgreSQL Database)]

            G --> J[agent_traces<br>run_id, step, tool_called, arguments]
        end
    end
